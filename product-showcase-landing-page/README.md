# Vantage Pro 14 — Product Showcase Landing Page

A single-page product showcase landing page inspired by premium tech-brand marketing pages. Built to practice layout composition, responsive design, and interaction polish using vanilla HTML and CSS — no framework, no JS yet.

## What it demonstrates

- Semantic HTML structure (`header`, `main`, `section`, `footer`)
- Responsive layout with a defined breakpoint at 768px
- CSS Flexbox for navigation and button layout
- Custom hover/active states and transitions (card lift, button press, image scale)
- Dark theme with a consistent gold accent palette
- Mobile-first considerations: stacked buttons, resized type, adjusted spacing at smaller viewports

## Tech

- HTML5
- CSS3 (Flexbox, gradients, `box-shadow` layering, transitions)
